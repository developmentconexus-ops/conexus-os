# A sweep (no wave)

A mechanical change across the code (arrow to `function`, branded ids, one `isRecord`) has no spec.
Its issue carries this standard:

```markdown
**Canonical pattern**: <the one right way, as code>
**Replaces**: <the shapes that are now wrong>
**Lever**: <the codemod or script that does it, and how to rerun it>
**Check**: <the lint rule or census line that only lets the number fall, and today's number>
**Unit**: one module per pull request
**Exceptions**: <none, or the exact cases>
```
