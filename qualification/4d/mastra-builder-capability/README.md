# 4D current Mastra Builder capability probe

This directory is Evidence-only. It is not Product implementation and creates
no root/Product dependency.

It proves only current mechanical composition on the exact lock:

- `createCodingAgent()` Workspace tool assembly and schema validation;
- real contained file read and local command execution;
- `AgentController` plan/build mode and persisted thread setting;
- Workspace skill discovery and BM25 indexing;
- Builder-facing display-state surfaces.

It does not call a model or E2B and does not prove coding quality, isolation,
current Mastra source admission, LSP/AST value, Git custody or Conexus Worker
Eval outcomes.

Reproduce with Node `24.18.0`:

```bash
npm ci
npm test
```

See [`4d-c02r-current-mastra-builder-capability-probe.md`](../../../docs/evidence/4d/4d-c02r-current-mastra-builder-capability-probe.md)
for interpretation and limitations.
