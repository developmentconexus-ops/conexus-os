# App starter

`files/` is the app a new Project starts from (`fixedApplicationStarterFiles` in
`apps/hub/src/builder/application-starter.ts` reads it). It is real source: the Builder's compiler
template can type check and build it as it stands, and `tests/implementation/builder-app-starter-v2.browser.test.mjs`
does so and boots it in headless Chromium under the Prévia's policy.

`files/app/src/components/ui` and `files/app/src/hooks` are generated by
`npm run builder:starter:components` from the shadcn CLI (`SHADCN_CLI_VERSION`, style `base-nova`,
Base UI, lucide icons) with three patches the script applies and fails loudly if shadcn moves them:
`cn` comes from `@/lib/utils`, overlays use the `scrim` token instead of the raw color `bg-black`,
and `chart.tsx` sets series colors on the container's `style` instead of an inline style element.
Each file keeps its MIT notice; the license text is `LICENSE-shadcn-ui.txt`. Pinned on 2026-09-28
(shadcn CLI 4.21.0; the registry's `react-day-picker` is `latest`, and the compiler pins the newest
9.x, 9.14.0, which the calendar type checks and renders against).

Everything else under `files/` (`main.tsx`, `router.tsx`, `routes/home.tsx`, `styles.css`,
`lib/utils.ts`, `lib/zod.ts`, `lib/format.ts`, `lib/errors.ts`, `index.html`) is written by hand. `styles.css` holds every color, radius and font;
its values are the neutral subset of `packages/brand/src/tokens.css`.
