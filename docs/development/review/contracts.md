# Review: Contracts

## Scope

The wire contracts: the OpenAPI documents, the routes generated from them, canonical JSON, and the checks that bind contracts to routes and to the operation ledger. Paths, as [`areas.json`](areas.json) lists them:

- `contracts/api/**`
- `apps/hub/src/generated/**`
- `packages/canonical-json/**`
- `scripts/check-wire-*.mjs`
- `scripts/generate-wire-projection.mjs`
- `scripts/generate-r1-s*-contracts.mjs`
- `scripts/run-kubb-wire-probe.mjs`
