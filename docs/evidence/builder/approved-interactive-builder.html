Um Builder para usar, não administrar
Esta é uma referência de experiência. A conversa, os modelos, a conta e os traces são simulados. O aplicativo no Preview é funcional.
01
Veja o agente construir.
Use Simular run no rodapé. A execução separa leitura, edição, compilação e carregamento do aplicativo.
02
Mude de modelo sem perder a conversa.
Escolha um modelo junto ao campo de mensagem. A execução em andamento mantém o modelo com que começou.
03
Teste o resultado.
Altere quantidades e desconto no aplicativo. Envie “Incluir frete” para simular a segunda versão.
04
Entenda uma falha.
Simule uma falha de compilação. A fonte avança, o Preview anterior permanece. Depois peça a correção.
05
Inspecione só quando precisar.
Código e alterações são somente leitura. “Ver execução” abre um trace ilustrativo, não dados reais do Mastra.
Pedidos livres reproduzem uma alteração de exemplo, não são interpretados por IA. Nada é enviado a um servidor. A continuidade fica no armazenamento local deste navegador, quando disponível. A demonstração não autentica contas, não chama modelos e não executa E2B.


Reiniciar a demonstração?
Isso limpa somente o roteiro e as preferências desta demonstração no navegador. Nenhum Project real será alterado.
