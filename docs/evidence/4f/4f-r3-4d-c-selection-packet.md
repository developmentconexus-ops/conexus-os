## Selection questions

Before implementation, the accepted owner packet must answer every question:

1. What exact package/source/version and physical boundary is selected?
2. Which protected property does it prove, and which alternatives were rejected?
3. Who owns migration, occurrence admission, cursor/merge and terminal truth?
4. Which restart, duplicate, stale-cursor, concurrent-writer, quiescence,
   missing-observation, coverage and drift falsifiers must turn red?
5. What read-only proof command and receipt establish each falsifier fired?
6. What source, package, schema or topology change triggers requalification?

An unanswered question remains a blocker; it is not filled from implementation
precedent.
